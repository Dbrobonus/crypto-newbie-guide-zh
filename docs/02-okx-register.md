| 操作 | 说明 |

| 1. 进入官方注册页 | 官方 App 或官网,不点广告链接 |

| 3. 填写邀请码 | "邀请码/推荐人"栏输入 **`61441349`**,显示"返现比例 20%"即成功 |

头像 → 身份认证 → 上传证件 → 人脸识别。注意:按 OKX 规则,**未完成身份认证的账户不产生返佣**,认证是必做项。

## 第三步:验证返佣生效
