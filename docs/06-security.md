# 安全与防骗清单:新手必做的 6 件事

> 更新:2026-07 · [返回目录](../README.md)

## 1. 开启二次验证(2FA)——注册后第一件事

路径:安全设置 → 绑定验证器。币安、OKX 都有 App 内置验证器,不需要额外安装软件;也可使用任意身份验证器 App。同时开启邮箱+短信验证。开启后即使密码泄露,他人也无法提币。

## 2. 只走官方渠道下载和登录

钓鱼网站与官网外观完全一致,每年都有人在假网站输入密码导致被盗。通过应用商店正版 App 或手动输入官网域名进入,永远不点搜索广告和陌生人发的"注册链接"。

## 3. 提币先小额测试

链上转账不可逆,地址填错或选错链基本无法找回。铁律:给任何新地址第一次转账,先转最小金额,确认到账再转大额。

## 4. C2C 防骗三条

- 全程只在平台内交易,私下交易 100% 是诈骗
- "客服"主动私聊让你先放币/扫码的都是假的
- 银行转账备注留空

## 5. 资产分层存放

交易所只放近期交易要用的资金;长期大额资产转入自托管钱包(硬件钱包最稳)。只用每月公布储备金证明的头部交易所。

## 6. 识别"保证收益"骗局

任何承诺固定收益、保本翻倍、"老师带单"的,一律是诈骗,没有例外。
