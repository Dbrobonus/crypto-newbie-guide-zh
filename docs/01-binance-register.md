# 币安(Binance)注册教程:10 分钟开户 + 20% 手续费返佣

> 更新:2026-07 · [返回目录](../README.md) · 网页版:[biruomen.com/binance-register.html](https://biruomen.com/binance-register.html)

**TL;DR**:① 通过官方渠道注册,在"邀请码"栏填 **`DBRO20OFF`**(20% 手续费返佣,注册后无法补填);② 上传身份证件完成实名认证;③ 设置里开启"BNB 抵扣手续费"再省 25%。叠加后交易成本最多降约 40%。

## 注册前的三个事实

1. 币安按交易量计是全球最大加密货币交易所,现货基础手续费 0.1%。
2. 注册填邀请码可获 20% 手续费返佣——官方推荐机制的最高比例,每笔交易后自动以现金返回现货钱包。
3. 邀请码**只能注册时填**,事后补绑需联系客服且不保证成功。

## 第一步:创建账号(2 分钟)

| 操作 | 说明 |
|------|------|
| 1. 进入官方注册页 | 通过官方 App(应用商店正版)或手动输入官网域名,不要点搜索广告或陌生链接 |
| 2. 邮箱/手机号注册 | 设置强密码 |
| 3. 填写邀请码 | 展开"邀请码(选填)",输入 **`DBRO20OFF`**,显示"返佣比例 20%"即成功 |
| 4. 验证码确认 | 输入 6 位验证码完成注册 |

## 第二步:实名认证 KYC(5 分钟)

未实名的账户无法充值和交易。路径:身份认证 → 选择国家/地区 → 上传身份证/护照/驾照 → 人脸识别。通常几分钟到几小时通过,只需做一次。

## 第三步:开启 BNB 抵扣(1 分钟)

路径:头像 → 账户 → "使用 BNB 抵扣手续费"开关。开启后现货手续费打 75 折(钱包需持有少量 BNB,10–20 USDT 等值即可用很久)。与邀请码返佣独立叠加:0.1% × 0.75 × 0.8 ≈ **0.06%**。

## 注册后第一件事:开二次验证

安全设置 → 绑定验证器(币安 App 内置验证器即可,也可用其他身份验证器 App)→ 同时开启邮箱+短信验证。开启后即使密码泄露,他人也无法提币。

## 常见问题

- **注册要花钱吗?** 不用,注册与实名免费,只有交易时收手续费。
- **返佣何时到账?** 每笔交易结算后自动进现货钱包,"分佣记录"可查。
- **怎么确认邀请码绑定成功?** 注册页显示"返佣比例 20%";注册后在"账户 → 推荐人"查看。
